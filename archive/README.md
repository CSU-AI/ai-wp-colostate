# Live-site archive

This directory contains generated historical reference material:

- `html/`: complete rendered HTML captured from each published page and post
- `crawl.csv`: URL, WordPress ID, title, dates, and corresponding archive files
- `media-inventory.csv`: Media Library metadata and source URLs

Regenerate with `python3 scripts/archive_live_site.py`. Generated files describe the live site at the capture time and should not be used as replacement-content drafts.
