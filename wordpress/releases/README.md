# Section releases

One file per production release: `YYYY-MM-DD-<section>.md`, plus the Redirection import CSV generated for it (`YYYY-MM-DD-<section>-redirects.csv`).

Each release note lists the pages published with their production IDs, menu changes, redirects imported, legacy pages unpublished, and the post-release checks run. See `../build-notes/production-workflow.md`.
