Code completion and chat inside your editor. CSU does not hold an enterprise GitHub Copilot license, so there is no central way to request one and no CSU data agreement behind it. Students and educators can verify their status with GitHub individually to get access at no cost. Because it is not covered by a CSU agreement, keep it to public or open source code and do not point it at repositories holding CSU institutional data. If you want an AI coding tool with CSU billing behind it, look at the Claude API pilot instead.
