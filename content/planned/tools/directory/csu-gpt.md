The general-purpose chat agent in Nebula One, open to anyone with a CSU NetID. Use it for everyday writing, summarizing, and questions when you do not need a specialized agent. Its models are hosted in CSU's own Azure tenant, and conversations are stored there and never used to train outside models. Web Search, when turned on, sends queries to Brave's search service outside CSU's tenant, so turn it off before working with Level 3 confidential data. If you need an agent grounded in specific documents or connected to a campus system, build your own agent in Nebula One.
