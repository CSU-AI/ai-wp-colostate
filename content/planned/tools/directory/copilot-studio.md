Microsoft's low-code builder for custom agents that automate a process or answer questions for a specific group. Notable strengths are automated test suites that score an agent's answers against expected ones, email-triggered agents, and a wide range of knowledge sources. Read the cost model carefully before you plan a public agent: if you share a Copilot Studio agent with people who do not hold a Copilot Premium license, their usage is billed to you as the creator. For agents meant for a broad or public audience, Nebula One is usually the better fit. Agents that use Level 3 confidential data have extra requirements for authentication, connectors, and web search; see Use AI With Level 3 Confidential Data.
