# Compare AI Tools

## Purpose

Compare approved and supported tools by task, data classification, access, cost, and major capabilities.

## Required content

- Filterable or scannable comparison matrix
- Allowed data classifications for every tool
- Availability and authentication requirements
- Cost and license information
- File, web, image, meeting, coding, and agent capabilities
- Limitations, accessibility status, and support destination

## Relationship to tool chooser

This page supplies the structured tool records used by the future chooser. See `docs/tool-finder-setup.md`.
