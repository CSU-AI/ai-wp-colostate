# Which AI Tool Should I Use?

## Purpose

Recommend appropriate tools based on the visitor's task, data, role, output, and working context.

## Required content

- Data-sensitivity safety gate
- Task, role, and output questions
- Recommendations drawn from the comparison dataset
- Reasons tools were included or excluded
- Contact path when no tool is appropriate
