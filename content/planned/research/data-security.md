# Research Data Security for AI

## Purpose

Help researchers match data classification and contractual requirements to approved AI environments.

## Required content

- Research-data classification path
- Approved environments by data sensitivity
- Restricted, regulated, export-controlled, and sponsor-controlled data cautions
- Storage, sharing, retention, and incident-reporting links
- Security consultation contact

## Editorial decisions needed

- Information Security and OVPR must approve the tool and data-handling matrix.
